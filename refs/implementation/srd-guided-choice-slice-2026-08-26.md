# SRD Guided Class and Species Slice

Date: 2026-08-26

This file is the implementation note for issue tracking of the first guided class/species expansion.

Goals:
- official SRD 5.2.1 class-first guided ordering;
- sticky acceptable-option pools with random-from-checked selection;
- all twelve SRD classes and nine SRD species represented in a licensed catalog;
- first mechanically enabled subset: Barbarian, Fighter, Monk, Rogue and Dwarf, Halfling, Human, Orc;
- fixed Soldier background remains the next seam to open;
- guided Standard Array is the first ability method attached to the new flow, while existing generation-method forms remain unchanged for regression coverage.

The remaining SRD classes/species are intentionally cataloged but disabled until their required spell or nested-choice native state can be represented without silent invention.
